# data/seed — 저장소 밖에서 받는 준비 자료

이 폴더의 자료 파일은 Git에 올리지 않아요(이 안내 파일만 올라가요). 팀 원칙상 직원 초기 데이터와 테스트 비밀번호는 따로 검토해 전달하기 때문이에요(`database/RESTORE.md`).

| 넣을 파일 | 쓰는 곳 | 받는 곳 |
| --- | --- | --- |
| `사내DB_직원가상데이터_구성초안_2.9.0.xlsx` | `tools/setup_db.py`의 직원 가데이터 16명(부서 계층·부서장·본인 입력·평정) | DB 담당 |

- 파일이 없으면 `setup_db.py`가 그 단계만 건너뛰어요. 이때 로그인할 수 있는 계정은 팀 DB 백업에 들어 있는 팀 테스트 계정뿐이에요(비밀번호는 DB 담당에게 확인).
- 직원 가데이터로 로그인하려면 `.env`의 `GP5_DEMO_PASSWORD`도 넣어야 해요(기본값 없음).
- Docker 이미지는 빌드할 때 이 폴더를 복사해요. 파일을 넣은 뒤 `docker compose up -d --build`로 다시 빌드해요.
- ERD는 팀 저장소 `docs/07_데이터베이스_저장소_설계/ERD_최종.html`을 써요. `tools/gen_schema.py`를 돌릴 때도 그 경로를 넣어요.
