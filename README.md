# SKN33-Final-2Team

SKN33 최종 프로젝트 2팀의 개발 저장소입니다.

현재 초기화 단계입니다. 프로젝트 상세 사양·기술 스택·설치 및 실행 방법은 확정 후 추가합니다.

## 협업 위치

- [팀 Notion](https://app.notion.com/p/ohgiraffers/SKN33_FINAL_2-_-3e9649136c1180f6b847e176dd888c98): 협업·그라운드룰, WBS·일정, 회의·일일 보고. 개별 협업 규칙은 팀 홈에서 연결합니다.
- [GitHub Issues](https://github.com/20260528-skn-family-ai-33/SKN33-Final-2Team/issues): 개발 작업 등록, 담당자·완료 조건·우선순위·세부 진행 기록.
- [Pull requests](https://github.com/20260528-skn-family-ai-33/SKN33-Final-2Team/pulls): 코드 변경·검증·사람 리뷰.
- Discord: 팀 사용 가이드와 공지·질문 공유.

GitHub Projects는 사용하지 않습니다. Notion에는 상위 업무와 이슈 링크를 남기고 개발 세부 상태는 Issues에서 관리합니다.

## 개발 순서

1. 이슈에 문제·범위·완료 조건·담당자·검토자·예상 기간을 기록합니다.
2. 최신 main에서 이슈별 작업 브랜치를 만듭니다.
3. 구현·검증 후 PR에 관련 이슈와 실제 검사 결과를 남깁니다.
4. 작성자 외 사람 1명 이상의 승인과 필요한 검사 통과 후 병합합니다.
5. 완료 조건 충족 후 이슈를 종료하고 관련 Notion 업무를 갱신합니다.

이슈는 Open 상태에서 본문에 `할 일 / 진행 / 검토`를 기록합니다. 완료 후 Closed로 전환하며 취소·중복은 사유를 구분합니다. AI 리뷰는 사람 승인을 대신하지 않습니다.

## 현재 설정 범위

최초 README로 저장소를 초기화합니다. 제품 코드·실행 환경·CI·브랜치 보호는 별도 작업으로 확인하고 추가합니다. 이 문서가 GitHub 설정을 자동 활성화하지는 않습니다.
